# 铜箔瑕疵检测数据集描述

> 本文档描述用于模型训练与评估的正式数据划分 `0921-formal-split`。图像原样存放在训练服务器
> `/share/data/cxz/copper-foil-defect-classification/0921-formal-split/`，由
> `code/split_formal_dataset.py --write --seed 42` 生成，权威说明见该目录下的 `README.md` 与 `split_manifest.csv`。

## 任务与类别

单标签图像分类，共 **9 类**铜箔表面瑕疵。类别名与标签文件 `configs/class_labels_csd.txt` 一致：

| 序号 | 类别 |
|---|---:|
| 0 | 凹凸点 |
| 1 | 刮伤 |
| 2 | 异物 |
| 3 | 气泡 |
| 4 | 结晶 |
| 5 | 针孔 |
| 6 | 铜瘤 |
| 7 | 陨石坑 |
| 8 | 黑点 |

## 图像规格

- 尺寸固定为 **200×200**（PNG）。项目正式管线禁止 resize，`datasets.py` 对其它 `--input_size` 直接报错。
- 全部图像**原样复制**自源目录 `Data/0920`，共 **9586 张**，源目录未做任何改动。

## 目录结构

符合 `torchvision.datasets.ImageFolder` 约定，可直接喂给数据加载器：

```
0921-formal-split/
├── train/  <类别>/<图像>
├── val/    <类别>/<图像>
└── test/   <类别>/<图像>
```

## 划分规则

逐类别独立处理，随机种子 **42**（按类别名单独播种，增删类别不扰动其他类的划分）。
对样本数 N，按整数比 `14:3:3 / 20` 切 `train = N*14//20`、`val = N*3//20`，**余数全部并入 test**：

- **N ≥ 1000**（7 类）：先随机抽 1000 张，这 1000 张按上述比例切；剩余 `N - 1000` 张全部划入 test。
  因此各类训练集恒为 **700 张**，类别间训练样本完全均衡。
- **N < 1000**（2 类）：直接按上述比例切三份，余数进 test。
