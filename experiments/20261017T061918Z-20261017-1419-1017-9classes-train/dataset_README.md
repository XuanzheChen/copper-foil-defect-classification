# Data/data/1017-formal-split-9classes

- 来源：`Data/data/1017`（共 12407 张；12337 张为 200x200，压坑类另有 70 张为其他尺寸）
- 目录结构：`<划分>/<类别>/<图像>`，可直接交给 `torchvision.datasets.ImageFolder`
- 随机种子：`42`（按类别名单独播种，增删类别不扰动其他类的划分）
- 图片为原样复制，源目录未做任何改动

## 划分规则

逐类别独立处理。设该类别样本数为 N，7:1.5:1.5 按整数比 `14:3:3 / 20` 计算，`train = N*14//20`、`val = N*3//20`、**余数全部并入 test**。

- **N >= 1000**（8 类）：先随机抽 1000 张，这 1000 张按上述比例切，剩余的 `x = N - 1000` 张**全部划入 test**，故 `test = 150 + x`。这样各类训练集恒为 700 张，类别间不再受原始数量差异影响。
- **N < 1000**（1 类）：直接按上述比例切三份，余数进 test。
