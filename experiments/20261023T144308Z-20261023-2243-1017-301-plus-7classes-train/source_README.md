## 数据校验与划分

- 统计日期：2026-10-23。所有图像均已完整解码校验，原始图像内容未修改。
- 压坑原有918张，压坑-plus的792张已改名为`原文件名主干-plus.扩展名`并移入压坑，共1710张；空的压坑-plus目录已移除。逐文件映射见`rename_manifest.csv`。
- 770组内容完全相同的压坑图像（每组2张），全部按要求保留；同一SHA-256组必须位于同一子集。压坑-plus相较原压坑仅增加22种不同内容。无跨类别重复、无跨子集SHA-256重复。
- 划分沿用种子42和既有逐类配额：N≥1000时train=700、val=150，其余归test；N<1000时train=N*14//20、val=N*3//20，余数归test。
- 为阻止重复内容泄漏，本次先按SHA-256分组，按组首个文件路径排序，以`random.Random("42-类别名")`打乱内容组，再按动态规划选取完整组凑足训练和验证配额，其余组归test。与旧的逐文件随机划分不同。
- 图像不缩放。8060张为200×200，229张保留原始尺寸；现有datasets.py在加载时排除非200×200样本，并输出排除清单。颜色模式P=7875、RGB=414，训练统一解码为灰度后扩展为三通道。
- 实际训练可用数：train=4299、val=913、test=2848。训练种子为现有默认0。

划分结果见[`../1017-301-plus-formal-split-7classes/README.md`](../1017-301-plus-formal-split-7classes/README.md)。完整源图校验记录见`image_audit.json`。
