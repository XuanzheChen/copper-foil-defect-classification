# 1104-301 去重后正式划分（7 类）

生成与核验日期：2026-11-04。

- 来源：[7类训练集1104/train](../../original/7类训练集1104/train/README.md)，原始 4438 张。
- 先按原始文件字节的 SHA-256 全局去重：16 组均各含 2 张，排除 16 张，保留 **4422 张**。
- 每组优先保留相对路径字符数最短的文件；长度相同按路径字典序选取。本次均保留无 ` (1)` 后缀的文件。
- 多余副本不进入 train、val 或 test；源目录全部 4438 张原图保持不变。
- 目录结构为 `<train|val|test>/<类别>/<图像>`；图像原样复制，不调整尺寸或颜色。

## 划分规则

- 使用去重后的类内数量 N；相对类别路径排序后，使用 `random.Random("42-类别名")` 独立打乱。
- N ≥ 1000：前 1000 张按 700/150/150 分配，超过 1000 的部分全部进入 test。
- N < 1000：train=N*14//20、val=N*3//20，其余进入 test。

## 核验结果

- 目标 4422 张图像的 SHA-256 均与源图一致，且所有目标哈希唯一；无类内、跨类或跨子集字节重复。
- 16 个排除路径均未进入任何子集；已核验保留路径与排除路径互斥，二者并集覆盖全部源图。
- 复制后再次核验全部源图的路径与哈希，确认源图未改变。
- 200x200 图像 4307 张，非 200x200 图像 115 张；尺寸和颜色模式分布见汇总文件。
- 源图均已通过前次 Pillow 完整解码核查；本次重新核验全部源图 SHA-256 与前次记录一致。
- 哈希去重仅识别文件字节完全相同的图像，不包含像素哈希或近似图像去重。
