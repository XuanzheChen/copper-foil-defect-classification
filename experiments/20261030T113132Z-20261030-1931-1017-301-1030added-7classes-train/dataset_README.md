生成与核验日期：2026-10-30。

- 来源：[1017-301-1030added](../1017-301-1030added/README.md)，已从拖尾删除 2 张与异物字节相同的图像，共 **7 类、6507 张**。
- 目录结构：`<train|val|test>/<类别>/<图像>`，可用于 `torchvision.datasets.ImageFolder`。
- 图像原样复制，源目录原图保持现有尺寸和颜色模式。

## 划分规则

- 随机种子：`42`。类内相对路径排序后，使用 `random.Random("42-类别名")` 独立打乱。
- 类别数量 N ≥ 1000：train=700、val=150，其余全部进入 test。
- 类别数量 N < 1000：train=N*14//20、val=N*3//20，余数进入 test。
- 全量原图参与划分，不缩放、不转换颜色、不排除非 200×200 图像。

## 核验结果

- 全部 6507 张图像均为 PNG，均可完整解码。
- 200×200 图像 6348 张；非 200×200 图像 159 张（刮伤 2、压坑 155、拖尾 2）。
- 颜色模式：`P` 6093 张，`RGB` 414 张。
- 全集 SHA-256 内容唯一，无类内、跨类别或跨子集的字节相同图像。该检查不等同于近似图像去重。
- 目标图像与源文件逐一核对 SHA-256 完全一致；划分清单覆盖全部源图像，每张恰好归属一个子集。
- 若训练管线仅接收 200×200 图像，实际可用 train=3830、val=815、test=1703，合计 6348 张。应明确训练时的尺寸和颜色处理规则。

## 逐文件归属与复现

逐文件归属见 [split_manifest.csv](split_manifest.csv)，列为 `split,class,filename`；filename 为类别目录内相对路径。

在工作区根目录执行：

```powershell
python code/split_formal_dataset.py --src "Data/data/1017-301-1030added" --dst "Data/data/1017-301-1030added-formal-split-7classes" --seed 42 --write
```

现有通用划分脚本生成的默认 README 含历史路径和“全部 200x200”说明；本 README 已按本次实际图像核验结果校正。重新运行该脚本后，应再次按实际尺寸更新说明。
